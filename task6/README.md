# Лабораторная работа №6: Змейка на Canvas

## Описание
Классическая игра «Змейка» с использованием Canvas API, паттерна MVC и ES-модулей. Игровой цикл реализован через `requestAnimationFrame` с `deltaTime` для постоянной скорости.

## Структура файлов (MVC)
- `model.js` — состояние игры, движение змейки, проверка столкновений, генерация яблока.
- `view.js` — отрисовка на Canvas (сетка, змейка, яблоко), обновление счёта в DOM.
- `controller.js` — игровой цикл, обработка клавиатуры, связка модели и представления.
- `index.html` — разметка.
- `style.css` — стили в тёмной гамме.

## Как запустить
Откройте `index.html` через Live Server или GitHub Pages. Управление — стрелками клавиатуры.
