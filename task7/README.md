# Лабораторная работа №7: Лента постов с бесконечным скроллом

## Описание
Асинхронная подгрузка постов с JSONPlaceholder API с реализацией бесконечного скролла, поиска с дебаунсом и обработкой ошибок сети.

## Структура файлов (MVC)
- `model.js` — состояние (посты, страница, фильтр), функция `fetchPosts` с `async/await` и `try/catch`.
- `view.js` — отрисовка карточек, индикатор загрузки, сообщения об ошибках.
- `controller.js` — обработчик скролла, дебаунс поиска, связка модели и представления.

## Как запустить
Откройте `index.html` через Live Server или GitHub Pages. Требуется интернет-соединение для работы с API.

## Ключевые особенности
- Дебаунс поиска (~300мс) через `setTimeout`/`clearTimeout`.
- Фильтрация по уже загруженным данным, без лишних запросов.
- Обработка ошибок сети с выводом сообщения пользователю.
