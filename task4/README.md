# Лабораторная работа №4: Игра «Быки и коровы»

## Описание
Реализация классической игры с использованием паттерна MVC и ES-модулей для разделения ответственности.

## Структура файлов (MVC)
- `model.js` – логика генерации числа и проверки попыток (не зависит от DOM).
- `view.js` – функции для обновления интерфейса (работает только с DOM).
- `controller.js` – связывает модель и представление, обрабатывает события.
- `index.html` – семантическая разметка.
- `style.css` – стили в темной цветовой гамме (темно-синий, бордовый, темно-зеленый).

## Как запустить
Откройте `index.html` через Live Server (VS Code) или любой локальный HTTP-сервер. 
*Примечание:* ES-модули (`type="module"`) требуют запуска через сервер из-за политики CORS, простое открытие файла двойным кликом может не сработать в некоторых браузерах.
