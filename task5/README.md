# Лабораторная работа №5: Игра Simon

## Описание
Классическая игра на память с использованием паттерна MVC и ES-модулей. Компьютер показывает последовательность цветов, игрок должен её повторить.

## Структура файлов (MVC)
- `model.js` — состояние игры, генерация последовательности, проверка ввода.
- `view.js` — отрисовка кнопок, подсветка, счётчики.
- `controller.js` — обработка кликов, управление потоком игры через `async/await` и `setTimeout`.
- `index.html` — разметка.
- `style.css` — стили в тёмной гамме.

## Как запустить
Откройте `index.html` через Live Server или GitHub Pages. ES-модули требуют HTTP-сервера.
