# Лабораторная №8–9. Todo-list на React

Часть 1: компоненты `App`, `TodoForm`, `Filters`, `Stats`, `TodoList`, `TodoItem`, состояние в `App`, передача через props.
Часть 2: сортировки (`[...todos].sort`), сохранение в `localStorage` через `useEffect`, мемоизация (`memo`, `useMemo`, `useCallback`).
Запуск: `npm install`, затем `npm run dev` (обычно http://localhost:5173). Готовая сборка: https://alekseykuralenko.github.io/web-course-2026/task8-9/published/ (обновляется командой `npm run build`).
